# AI-Based-Customer-Conversion-Predictor
This project identifies and prioritizes leads likely to convert into paying customers for an online Education Technology startup. Using Decision Tree and Random Forest models, it covers the full data science lifecycle, including EDA, preprocessing, model tuning, evaluation, and interpretation to drive actionable insights.
Keywords: Machine Learning, Random Forest, Lead Scoring, Customer Conversion, Recall Optimization, Hyperparameter Tuning, Feature Importance, Classification, EdTech, Predictive Analytics
